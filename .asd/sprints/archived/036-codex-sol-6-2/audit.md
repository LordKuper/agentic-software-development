## Risks
- Old Codex clients: impact = consumers on codex-cli < 0.167.0 get HTTP 400 `model_not_found` at first `sol` dispatch; External Review under Claude Code with an old PATH CLI reads as unavailable; mitigation = AC-3 states the minimum in README and CHANGELOG.
- AC-7 vs user-wait ids: `sprint-lifecycle.md` "Operation timing" names a user-wait `wait <gate>`, so a gate asked twice in one sprint (a revised scope gate, a second reviewer question) reuses the id and would be refused once closed ids are; impact = lost wait records or a broken convention; mitigation = plan gives repeatable ids a numbering rule (as phase ops get `#<n>`) in the same change.
- AC-7 repeated-flag warning lives in the shared `parseFlagArgs`; impact = every runtime command gains the warning; mitigation = intended (034#A-1 already warns on unknown flags), tests cover one other command.
- AC-9 reverses sprint 035's user-kept AC-15 exception; impact = more reviewer re-dispatches on comment-only rounds (one dispatch ≈ 5 min, retro 035 P-1); mitigation = user explicitly included P-1 at this scope gate.
- AC-12 changes the commit form every dev/tester/orchestrator commit uses; impact = a wrong form blocks all commits; mitigation = keep `--subject` working, add the message input, pin it in `tests/run.js`, update `git-strategy.md:44`, `asd-phase-cleanup.md:24` together.
- AC-14 accepting a return file as "finished" must not mask a dispatch that wrote a valid file then hung; impact = liveness stops watching it; mitigation = finished means the orchestrator reads that return file next, as on completion.
- Stale host-version notes outside scope: `providers.md:44` "Verified on codex-cli 0.156.1", `config.yaml:40` comment "codex-cli 0.150.1"; left unchanged (no AC covers them).
