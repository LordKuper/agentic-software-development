| 1 | high | .asd/runtime.js:1368, .asd/runtime.js:1384, .asd/runtime.js:1397-1400 (AC-15) | `commentOnlyLines` can read code as a comment. That is the unsafe direction: a code change keeps a stale APPROVE latch, against AC-15's "a round that changes at least one production executable file clears ... latch". The ponytail doc claims that the lexer's naive reading only ever counts code as code ("a string is never read as a comment"). Two input classes break that claim. (a) A regex literal holding `\/*`, such as the trailing-slash strip `s.replace(/\/*$/, '')`: the `/*` in code state opens `block` (1397-1400), and every later line up to the next `*/` is marked comment-only. An edit to any of those code lines then counts as comment-only. The previous line-text rule read those lines as code, so this regression comes from this diff. (b) Multi-line `'`/`"` strings, which are legal in kt, java (text blocks), php, rs, swift, scala, dart, groovy, cs and cpp (raw strings), all in the lexed family. Line 1384 resets the string state at each line end, so the string's content lines are lexed as code. A content line that starts with `//` reads as a comment, and one holding an unclosed `/*` puts the following real code lines into `block`. No test covers either class: tests/run.js:10355-10394 checks only `//` inside a single-line string and a backtick template literal. | Keep the cheap lexer, but make it stop at what it cannot follow: at a line end, if the state is `string` with a non-backtick quote (an unterminated `'`/`"`), or `block` opened after code on the same line, return `lines` as they stand, so every later line counts as code. A block that opens at the start of a line (a JSDoc opener) keeps today's behaviour, so the AC-15 JSDoc cases stay green. Rewrite the doc's ceiling sentence to name the remaining limit (for example, a regex holding a backtick). Add asserts to the AC-15 test: `comment('a.js', "x = s.replace(/\\/*$/, '');\nrun();\n", 2)` is false, and `comment('a.kt', 'val s = """\n// x\n"""\n', 2)` is false. Each needs a mutation proof that removes the stop. |
