## Risks
- Transition release gap. impact = this sprint's own version is never tagged, since 023's closure write no longer tags. mitigation = 022's merge mode runs the new canon from the sprint branch; the retry route also recovers it.
- `NEXT: done` read as a `phase="done"` write. impact = an early terminal write on base. mitigation = the "PR phase" semantics note plus merge mode's "no state … on any branch".
- Offline warn-and-resume (AC-4). impact = a sprint hand-merged earlier resumes on a stale base until the next online run. mitigation = the warning names it; the next online run detects it.
- Amendment base (AC-7). impact = a lower floor for concurrent fixes in the same iterations and an extended cap. mitigation = amendments are a hard user gate; lower is the conservative direction.
- Tests L6842 and L6860 pin tokens that are kept on purpose.
- Missed restating sites. mitigation = the plan assigns every Touched-areas site to one Task, one Task per multi-AC rule doc.
- Change surface: about 25 files in the pathspec (generated views excluded), likely one review wave.
